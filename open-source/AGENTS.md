# 神念社区工程

完整工程共用一套手机 App，实现位于仓库根的 `packages/app`；本目录包含 Wire、Shared、Server / Worker、扩展契约、Client / CLI、协议 SDK、自托管运维工具和公共文档。源码构建、单元测试、原生运行与部署验收是不同证据，不把其中一项通过解释为所有平台 / 功能验收。

## 开发边界

- 代码、必要规范和测试一起维护；先读 README 与 docs，改行为必须补定向测试。
- 由维护者从唯一开发源受控同步；改动先在同一实现上审阅和验证，不在两个仓库分别修改 App 后长期双向复制合并。
- 公共实现不得依赖私有模块、内部文档、官方密钥、官方数据库或专用网络。
- 单元测试只验证代码，不启动真实 Agent、不创建线上会话、不读取用户实际配置或工作空间；夹具放系统 tmp 的 shennian-tests/unit 下并精确清理。
- 不提交环境配置、私钥、模型 Key、账号 Token、个人数据、完整用户日志或备份。配置示例只放空值或明确占位符。
- 不擅自发布软件、升级现有实例、改数据或推送公共仓库。Desktop 已暂停，不恢复其开发或发布。
- 协议、权限、迁移、签名和升级行为必须专项验证，不能因单元测试通过就声称实机升级已验收。

## 本仓库检查

以下为 Core 独立检查，在本目录执行；完整仓库根命令另包含 App，见根 README 与 docs/mobile-app.md。

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm test
pnpm test:deploy
```

以上命令不要求父工程或私有仓库。许可状态见 LICENSE-STATUS.md；商业政策说明不是完整软件许可证。
