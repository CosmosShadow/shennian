# Wire 协议与兼容边界

`packages/wire` 是跨手机、Client 和 Server 的消息、会话与能力契约唯一源，无运行时依赖；不读取环境变量或连接服务。接口、实现和单元测试随包提供。独立公共工程运行 `pnpm build`、`pnpm test`，无需父工程或数据库。

## 职责

- 实例 origin：规范化与严格输入校验；不靠带 Token 的 URL 自动切换实例。
- 群、会话和同步：成员关系、会话索引、事件与恢复状态；区分个人会话与群权威来源。版本不支持时返回明确的升级或隔离处理，不静默吞并历史。
- Agent 与工作空间：主机 / Agent 身份、执行能力、设置与授权元数据。凭据不作为普通客户端可见设置。
- 文件与应用：使用既有目录、应用登记和授权边界；路径 / 项目标识不构成访问授权。
- 消息与附件：结构化负载、可展示工具结果及输入约束；大正文与工具结果不能因同步而无限展开。
- 提醒、语音与外部工具：传输数据契约，不代表所有供应商或 UI 已启用。

协议类型与输入归一化不是鉴权实现：Server 与 Client 仍须验证 owner、成员、machine、revision、会话范围与操作权限。线上已有 Wire / API 字段默认保持兼容；改协议不能只改 TypeScript 类型而跳过旧客户端和数据迁移验证。
