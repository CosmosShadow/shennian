# Shared 客户端运行契约

`packages/shared` 是手机和其他受支持消费者共同使用的状态 / 同步库，唯一源随公共工程提供，不依赖私有模块、父工程文档、生产数据库或 Provider Key。当前不是完整 App 或 Server 源码包。

## 组成与边界

- `lib/api` 与 auth store 管理实例 API、会话身份和能力数据；地址切换不能携带另一实例 Token，Client 与 Server 仍须独立鉴权。公开类型或本地 store 不构成权限校验。
- `relay` / `relay-manager` 负责已授权连接、重连、生命周期与恢复；永久拒绝、离线、后台暂停和临时故障不能全部视为无限重试。关闭后不得保留计时器或重复订阅。
- `sync-engine` / `sync-session-runtime` 与 stores 处理消息 / 会话索引、增量合并、恢复和本地持久接口；群消息与本机会话不是两个互相覆盖的权威。先写本地成功不代表服务端已确认，撤权和删除也不能靠重放历史恢复。
- `storage` 定义本地索引端口，由消费者提供具体实现；不得默认读取另一实例或用户的真实工作空间。字段和迁移语义须兼容已发布消费者。
- 会话、项目、机器、Agent 权限、未读和主题等辅助函数是共享表示 / 合并逻辑，不能替代 Server 成员权限或 Client 文件权限。
- 历史 account tier / entitlement 类型用于兼容现有 API，与「20 人商业授权」不是一回事；本次迁移不新增席位锁、商业 License 校验或付费解锁条件，不重写官方业务策略。
- `i18n` 提供中英文字典，消费者从同一源构建，不另维护一份翻译。同步更新语义和测试，不把内部经营资料放入字典。
- runtime metrics 只描述运行观测接口；不默认向官方回传企业用户数据。

## 构建、测试与修改

公共根 `pnpm build` 构建 Wire、扩展契约和 Shared，`pnpm test` 运行包内单元测试。Shared 的外部依赖是 Zustand 与 React peer；无需数据库、模型配置或私有包。测试使用模拟 API / WebSocket 和内存持久接口，不启动真实 Agent，不写正式工作目录。协议兼容、离线恢复、消息排序、删除 / 权限边界和生命周期修改应补对应测试。

移动代码目录不改变包名 `@shennian/shared`、导出路径、Wire 字段或运行行为。集成工作区同步消费者路径、workspace 锁文件和发布输入范围；不保留旧目录桥，也不复制第二份核心。暂停维护的 Desktop 不作为开发 / 测试 / 发布对象；仅随工作区生成的依赖链接更新，不恢复其界面或发布。
